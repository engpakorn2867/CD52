# แผนที่คาดการณ์น้ำล้นตลิ่ง แม่น้ำแม่กลอง จ.ราชบุรี

ระบบแผนที่ดาวเทียมสำหรับประเมินว่า **เมื่อระดับน้ำแม่กลองเกินตลิ่ง น้ำจะแพร่กระจายไปถึงพื้นที่ใดบ้าง ลึกเท่าไร และเสียหายประมาณเท่าไร**
โดยใช้ **สถานี K.55A สะพานรถยนต์ค่ายหลวง อ.บ้านโป่ง** เป็นเกณฑ์หลัก ร่วมกับสถานีวัดระดับน้ำอื่นในจังหวัดราชบุรีจาก
คลังข้อมูลน้ำแห่งชาติ [thaiwater.net](https://www.thaiwater.net/)

## วิธีใช้งาน

```bash
node server.js          # ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม
# เปิด http://localhost:8080
```

`server.js` ให้บริการไฟล์หน้าเว็บ และเป็นตัวกลาง (`/api/thaiwater/waterlevel`) ดึงข้อมูลจาก
`api-v3.thaiwater.net` (แคช 5 นาที) เพื่อเลี่ยงปัญหา CORS ของเบราว์เซอร์
จะเปิดไฟล์ `index.html` ตรงๆ หรือวางบน GitHub Pages ก็ได้ ระบบจะลองเรียก API ของ ThaiWater โดยตรง
และถ้าไม่สำเร็จ สามารถคัดลอก JSON จาก thaiwater.net มาวางในช่อง “วาง JSON” ได้

### หน้าจอ

1. **ระดับน้ำ K.55A และการคาดการณ์** — ระดับตลิ่ง **9.00 ม.รทก. ทั้งสองฝั่ง** รองรับน้ำได้ **1,730 ลบ.ม./วินาที**
   - **คาดการณ์ตามเวลา** (ค่าเริ่มต้น): ค่าล่าสุด 30 ก.ย. 2569 09:00 น. = 10.21 ม. (ล้นตลิ่ง 1.21 ม.) ต่อด้วยตารางคาดการณ์
     ถึง 22:26 น. (12.00 ม.) แล้วต่อยอดตามสมมติฐาน 3 แบบ (ดีที่สุด / ค่ากลาง / เลวร้าย) ไปอีกหลายวัน (ค่าเริ่มต้น 5 วัน)
     มีกราฟระดับน้ำตามเวลา (ชี้ดูค่า / คลิกเพื่อดูแผนที่ ณ เวลานั้น) และตารางรายชั่วโมง
   - **กำหนดสถานการณ์เอง**: ป้อนระดับหรือปริมาณน้ำคงที่ พร้อมระยะเวลาน้ำล้น
2. **ข้อมูลล่าสุดจาก ThaiWater** — รายการสถานีในราชบุรี (และใกล้แม่กลองในเขตคำนวณ) เรียงตามระดับที่เกินตลิ่ง
   🔴 น้ำล้นตลิ่ง · 🟠 ใกล้ล้น (< 0.5 ม.) · 🟢 ปกติ ถ้าพบสถานี K.55A ระบบจะตั้งค่าระดับน้ำปัจจุบันให้อัตโนมัติ
3. **ผลคาดการณ์** — ระบบจำลองการไหลของน้ำ 2 มิติตามเวลา (ค่าเริ่มต้น 48 ชม. ใช้เวลาคำนวณ 5–30 วินาที เห็นน้ำแผ่ออกบนแผนที่ระหว่างคำนวณ)
   แล้วสรุป: พื้นที่ท่วม, **ระดับอันตรายต่อคน** 4 ระดับ, **ความเร็ว/ความแรงของน้ำ**, พื้นที่น้ำไหลแรง ≥ 1 ม./วินาที,
   เขตบ้านเรือนที่เสี่ยงเสียหายหนัก, **ความเสียหายทางเศรษฐกิจแยกตามการใช้ที่ดิน** (บ้านเรือน / นาข้าว-พืชไร่ / สวน)
   และเงินช่วยเหลือเกษตรกรตามเกณฑ์ รายชื่อชุมชน (OpenStreetMap) เรียงตามระดับอันตราย พร้อมเวลาที่น้ำจะมาถึง
4. **แผนที่** — ภาพดาวเทียม Esri/Google เลือกชั้นแสดงผลได้ 5 แบบ:
   **ความลึก** · **ความแรงน้ำ** (สี + ลูกศรทิศทางการไหล) · **อันตราย** · **ความเสียหาย** (บาท/ตร.ม.) · **เวลาน้ำถึง**
   แถบเวลา/ปุ่ม ▶ เล่นย้อนดูน้ำแผ่ออกทีละชั่วโมง คลิกจุดใดก็ได้เพื่อดูความลึก ความเร็ว ทิศทางน้ำ เวลาที่น้ำมาถึง
   ระยะเวลาท่วมขัง ระดับอันตราย และความเสียหายต่อไร่ ณ จุดนั้น

### แผนที่ตำบล หน่วยงานรับผิดชอบ และชุดปฏิบัติการ (`tambon-map.html`)

เปิด `tambon-map.html` (หรือคลิกลิงก์ใต้หัวเรื่องในหน้าหลัก) แต่ละแผนที่มีปุ่ม **บันทึกเป็นรูป (PNG)**:

- **ทั้ง อ.บ้านโป่ง (15 ตำบล)** — ระบายสีตามแม่น้ำ หรือไม่ระบายสี
- **แผนที่เจาะจงตำบล** — เพิ่มได้หลายภาพ แต่ละภาพเลือก **1–5 ตำบล** จากทั้ง 15 ตำบล (ค่าเริ่มต้น: บ้านม่วง, คุ้งพยอม)
- **แยกส่วนตำบล** — เว้นขอบขาวระหว่างตำบล และวาดกรอบสีหน่วยงานไว้ด้านในแต่ละตำบล ตำบลที่ติดกันสีเดียวกันจึงไม่ดูเป็นผืนเดียว

**คาดการณ์น้ำท่วมและความเสียหาย** (การ์ดบนสุด): ตลิ่ง 9.00 ม.รทก. (1,730 ลบ.ม./วินาที) ค่าเริ่มต้นระดับน้ำ 10.67 ม.
- ปรับ **ระดับน้ำ** (ม.รทก.) หรือ **ปริมาณน้ำ** (ลบ.ม./วินาที) ได้ — ผูกกันตามโค้งความสัมพันธ์ K.55A หรือปลดให้แยกกันก็ได้ · ปุ่ม −0.25 / +0.25 / +0.5 / +1 ม.
- พื้นที่คำนวณจาก **พื้นที่จริงริมแม่น้ำ**: DEM (~37 ม., ปรับเขตอาคาร/ต้นไม้เป็นระดับพื้นดิน) + การใช้ที่ดิน ESA WorldCover
  น้ำล้นเข้าจากตลิ่งช่วงที่ผ่าน อ.บ้านโป่ง แล้วไหลตามที่ต่ำที่ต่อเนื่องกัน (priority flood คำนวณล่วงหน้าใน `data/banpong-flood.js` ด้วย `tools/build_flood_grid.js`)
- โหมด **ตามปริมาณน้ำที่ล้น × เวลา**: เติมน้ำปริมาตร (Q − 1,730) × ชั่วโมง ลงที่ลุ่มที่น้ำไปถึงจากที่ต่ำสุดขึ้นมา · โหมด **ขอบเขตสูงสุด**: เต็มระดับน้ำทุกจุดที่ไหลถึง
- ผลรายตำบล: พื้นที่ท่วม (ไร่) แยกชุมชน/นา/สวน/อื่นๆ, ความลึกเฉลี่ย/สูงสุด, สัดส่วนชั้นความลึก, ความเสียหาย (บาท, โค้ง JRC เอเชีย, มูลค่าปรับได้),
  **แถบเสี่ยง** (ถ้าน้ำขึ้นอีก 0.25–1 ม.) และ **ระดับน้ำที่ตำบลเริ่มท่วมเป็นวงกว้าง** · บันทึกตารางเป็น CSV
- แสดงความลึกน้ำบนทุกแผนที่ (ทั้งอำเภอ/เจาะจงตำบล) พร้อมสรุปในกล่องด้านขวาของภาพ
- **จุดน้ำเข้านอกจากล้นตลิ่ง** — เครื่องมือ *ปักท่อระบายน้ำ* / *ปักหนอง/บึง* ใต้แผนที่: ใส่ระดับท้องท่อ (ม.รทก., ไม่ทราบ = พื้นดิน − 1.5 ม.),
  รัศมีพื้นที่รับน้ำ และสถานะ (เปิด / มีบานกันน้ำย้อน / ปิด + เครื่องสูบ) — เมื่อระดับน้ำสูงกว่าท้องท่อ น้ำย้อนท่อขึ้นมาที่ต่ำในรัศมีนั้น
  ผิวน้ำเท่าระดับแม่น้ำ (สีม่วงบนแผนที่ ไม่ใช้ปริมาตรน้ำล้นตลิ่ง)
- **จุดน้ำท่วมจริงจากหน้างาน** — เครื่องมือ *ปักจุดน้ำท่วมจริง*: กรอกความลึกที่วัด (0 = แห้ง) และระดับน้ำ K.55A ขณะวัด
  ระบบปรับระดับพื้นดินรอบจุด (ถ่วงน้ำหนักตามระยะ รัศมีปรับได้) ให้ตรงกับที่วัด แล้วคำนวณการแผ่ของน้ำใหม่ (priority flood ในเบราว์เซอร์ ~0.3 วินาที)
  จุดที่พบน้ำถือเป็นหลักฐานว่าน้ำแม่น้ำเข้าถึงบริเวณนั้นได้ (เช่น ย้อนท่อ) · ตารางแสดงความลึกตามแบบจำลองเทียบกับที่วัด
- ข้อสังเกตจากข้อมูลความสูง: ฝั่งตะวันออก (ท่าผา กรับใหญ่ ปากแรต หนองกบ หนองอ้อ ดอนกระเบื้อง สวนกล้วย นครชุมน์) เริ่มท่วมเป็นวงกว้างที่ ~10.64 ม.
  ฝั่งตะวันตก (บ้านม่วง คุ้งพยอม หนองปลาหมอ) ~10.92 ม. · เบิกไพร ลาดบัวขาว เขาขลุง ~11.0 ม. · ตัวเมืองบ้านโป่ง ~11.3 ม. (DEM คลาดเคลื่อนได้ ±0.5–1 ม.)

**บัญชีกลุ่มเปราะบาง — เข้าช่วยเหลือเป็นลำดับแรก**: นำเข้าทะเบียนผู้ป่วยกลุ่มเปราะบาง (.xlsx/.csv คอลัมน์ ชื่อ, กลุ่มเปราะบาง(ADL)/พิการ, บ้านเลขที่, หมู่ที่, ตำบล, รพ.สต.)
- จัดระดับความเร่งด่วน: **1 ติดเตียง** (ADL 0–4) · **2 ติดบ้าน/พิการการเคลื่อนไหว-การมองเห็น** (ADL 5–11) · **3 พิการทางจิต สติปัญญา การได้ยิน การพูด** · 4 ไม่ระบุ
  (รับคำสะกดผิด เช่น “ติดเดตียง” และคะแนน ADL ที่เป็นตัวเลข)
- เลือกตำบล (ค่าเริ่มต้น คุ้งพยอม + บ้านม่วง) · ปักตำแหน่งหมู่บ้านด้วยเครื่องมือ *ปักตำแหน่งหมู่บ้าน* → ระบบดูว่าหมู่บ้านอยู่ในพื้นที่น้ำท่วมตามการคาดการณ์หรือไม่
- ลำดับช่วย: หมู่บ้านที่น้ำท่วม → เสี่ยงท่วม → ยังไม่ปักตำแหน่ง → ไม่ท่วม แล้วตาม **หมู่ริมน้ำ → ใกล้น้ำ 1–2 กม. → ไม่ทราบ → ห่างน้ำ** แล้วจึงระดับความเร่งด่วนและความลึกน้ำ
- ตาราง “หมู่บ้านริมน้ำ”: ค่าเริ่มต้นใน `data/banpong-moo-river.js` ประมาณจากที่อยู่สถานที่ใน Overture Maps ที่ระบุ “หมู่ X” (ยังไม่ยืนยัน แสดง “(ประมาณ)” ในภาพ)
  แก้ไขและติ๊ก “ยืนยันแล้ว” ได้ตามข้อมูลจาก อบต./ผู้ใหญ่บ้าน (เก็บในข้อมูลส่งออก/นำเข้า)
- ภาพสำหรับบันทึก/พิมพ์ (A4 แนวนอน): หน้าสรุปรายหมู่บ้าน + รายชื่อเรียงลำดับ (ช่อง “ชุดปฏิบัติการ” และ “ช่วยแล้ว ☐”) · CSV · ปิดบังนามสกุลได้
- แผนที่: วงกลมรายหมู่บ้าน (ตัวเลข = จำนวนคน สีตามระดับสูงสุด ขอบฟ้า = หมู่บ้านน้ำท่วม) และสรุปในกล่องด้านขวา
- **ข้อมูลส่วนบุคคล**: อ่านและเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ส่งออก ไม่รวมในลิงก์ที่แชร์หรือปุ่มส่งออก JSON มีปุ่มลบออกจากเครื่อง ·
  ไฟล์ .xlsx ถูกกันไม่ให้ commit ใน `.gitignore` · ตัวอ่าน Excel: SheetJS (`vendor/xlsx`, Apache-2.0)

**หน่วยงานรับผิดชอบ**: สี, ชื่อหน่วยงาน, ผู้รับผิดชอบ, เบอร์โทร, หมายเหตุ · เครื่องมือ **คลิกตำบล** / **วาดกรอบ** / **ลบกรอบ**

**ชุดปฏิบัติการ**: ชื่อชุด, หน่วยงานต้นสังกัด, หัวหน้าชุด, เบอร์โทร, กำลังพล, ยานพาหนะ/อุปกรณ์, หมายเหตุ, ตำบลที่รับผิดชอบ
และ **วางจุดชุดปฏิบัติการ** บนแผนที่ (หมุดหมายเลข) — กล่องด้านขวาของภาพแสดงหน่วยงานและชุดปฏิบัติการในภาพนั้น (ติดไปกับ PNG)

ข้อมูลบันทึกในเบราว์เซอร์อัตโนมัติ และ **ส่งออก/นำเข้า** (ข้อความ JSON หรือไฟล์) เพื่อสำรองหรือส่งต่อ

ผลจำแนก: สีแดง 9 ตำบล (นครชุมน์ ท่าผา เบิกไพร ลาดบัวขาว ปากแรต บ้านโป่ง บ้านม่วง สวนกล้วย คุ้งพยอม) ·
สีเหลือง 5 ตำบล (กรับใหญ่ หนองกบ หนองอ้อ ดอนกระเบื้อง หนองปลาหมอ) · สีเทา 1 ตำบล (เขาขลุง)
พื้นหลังเริ่มต้นเป็น **แผนที่ถนนสีเทา** (แบบแผนที่เขตของหน่วยงาน: ถนน คลอง ชื่อหมู่บ้าน วัด โรงเรียน เส้นแบ่งเขตเป็นเส้นประ)
จากข้อมูล Overture Maps / OpenStreetMap ที่ฝังในเครื่อง (`data/banpong-basemap.js` ใช้งานได้แม้ไม่มีอินเทอร์เน็ต)
เลือกพื้นหลังแบบเรียบหรือภาพดาวเทียมได้ ขอบนอกตำบลปรับให้ตรงขอบอำเภอจาก OpenStreetMap แล้ว
แต่แนวเขตระหว่างตำบลยังเป็นแบบย่อ จึงอาจไม่ตรงแนวแม่น้ำพอดี
สร้างข้อมูลแผนที่พื้นฐานใหม่ได้ด้วย `pip install pyarrow shapely && python3 tools/overture_basemap.py`

## ข้อมูลอ้างอิง

| ข้อมูล | แหล่ง |
|---|---|
| Rating Curve และระดับตลิ่ง K.55A | ศูนย์อุทกวิทยาชลประทานภาคตะวันตก / สำนักงานชลประทานที่ 13 กรมชลประทาน |
| ระดับน้ำล่าสุดทุกสถานี | คลังข้อมูลน้ำแห่งชาติ `api-v3.thaiwater.net/api/v1/thaiwater30/public/waterlevel_load` |
| ความสูงภูมิประเทศ (DEM) | AWS Terrain Tiles (Terrarium; SRTM ฯลฯ) ~37 ม./พิกเซล (หรือ ~18 ม. โหมดละเอียด) |
| การใช้ประโยชน์ที่ดิน | ESA WorldCover 10 ม. ปี 2021 (CC BY 4.0) ย่อเป็นตาราง ~19 ม. ใน `data/landcover.js` |
| ภาพดาวเทียม | Esri World Imagery, Google Satellite |

### ขั้นที่ 0.5: ปรับพื้นดินเขตอาคาร/ต้นไม้ (`js/terrain.js`)

DEM ดาวเทียม (SRTM) วัดถึงหลังคาอาคารและยอดไม้ ในตัวเมืองบ้านโป่งอ่านได้ ~15 ม. (ค่ากลาง) ขณะที่นา/ที่โล่งรอบๆ ~11 ม.
ถ้าใช้ค่าดิบ แบบจำลองจะเห็นตัวเมืองเป็น “เนิน” สูงกว่าระดับน้ำ น้ำจึงไม่เข้าเมือง (ผลของรุ่นก่อนหน้า)

ระบบจึงหาระดับที่โล่งอ้างอิง (เปอร์เซ็นไทล์ 30 ของนา/ทุ่งหญ้า/ที่โล่งในบล็อก ~2 กม.) แล้วกดเซลล์อาคาร/ต้นไม้ไม่ให้สูงเกิน
ระดับนั้น + 0.5 ม. (ชุมชนมักตั้งบนที่ดอนริมน้ำเล็กน้อย) และลดได้ไม่เกิน 5 ม. (ไม่กดภูเขา) — แนวคิดเดียวกับ FABDEM แบบย่อ
ปิด/ปรับได้ในหน้าตั้งค่า ค่าเหล่านี้เลือกให้สอดคล้องกับแผนที่ประเมินของ IPB (3,000 ลบ.ม./วินาที ครอบคลุมตัวเมืองบ้านโป่ง)

การจำลองการไหลใช้เซลล์หยาบ (~100–300 ม.) แล้ว **ย่อผลลงพิกเซลละเอียดแบบรักษาปริมาตร** (เติมน้ำจากพิกเซลต่ำสุดขึ้นไป)
เพื่อไม่ให้เซลล์ที่มีน้ำตื้นแสดงพื้นที่ท่วมกว้างเกินจริง

### ขั้นที่ 1: จุดน้ำล้นและขอบเขตเสี่ยง (`js/flood.js`)

1. **ระดับน้ำตามลำน้ำ** — ระดับที่ K.55A (จาก Q หรือ H) เป็นจุดยึด ระดับที่จุดอื่นลดลงตามความลาดชันผิวน้ำ
   (ค่าเริ่มต้น 0.15 ม./กม. ได้จากแนวโน้มความสูงตลิ่งใน DEM ช่วงท่ามะกา–ราชบุรี)
   ถ้ามีข้อมูลสถานีอื่นในราชบุรี จะใช้ระดับตลิ่งของสถานีนั้นเป็นจุดควบคุมเพิ่ม และประมาณค่าระหว่างสถานีตามระยะทางลำน้ำ
2. **ระดับตลิ่งตามลำน้ำ** — ระดับตลิ่ง K.55A (9.00 ม. ทั้งสองฝั่ง) + ความลาดชัน + ส่วนที่ตลิ่งสูงกว่าแนวโน้มจาก DEM
   (เช่น ย่านเมือง ที่ดอน) คูณน้ำหนัก 0.5 — DEM ดาวเทียมสูงกว่าพื้นจริงหลายเมตรในเขตเมือง/ต้นไม้
   จึงใช้เพียงส่วนเบี่ยงเบนเฉพาะที่ ไม่ใช้ค่าสัมบูรณ์
3. **จุดน้ำล้น** — ช่วงลำน้ำที่ระดับน้ำ > ตลิ่งฝั่งนั้น (แยกฝั่งซ้าย/ขวา มองตามทิศน้ำไหล)
4. **การแพร่กระจาย** — น้ำไหลจากจุดล้นไปยังพิกเซลที่ติดกัน (8 ทิศ) ที่พื้นดินต่ำกว่าระดับน้ำ ต้องเชื่อมต่อกันเท่านั้น
   (แอ่งต่ำที่มีที่ดอนกั้นไม่นับ) และไม่เกินระยะแพร่กระจายสูงสุด (12 กม.)
   ผลนี้คือ “ขอบเขตเสี่ยงสูงสุด” (สีเหลือง) และเป็นโดเมนของการจำลองการไหลในขั้นที่ 2

### ขั้นที่ 2: การไหลของน้ำ ความแรง และความเสียหาย (`js/hydro.js`)

1. **ปริมาณน้ำที่ล้น** = Q ที่ K.55A − Q ตลิ่งเต็ม (1,730 ลบ.ม./วินาที) ตามกราฟคาดการณ์ (หรือคงที่ในโหมดกำหนดเอง)
   แบ่งให้แต่ละจุดล้นตามสมการฝาย (ความสูงที่น้ำเกินตลิ่ง)^1.5 จุดใดที่น้ำบนตลิ่งสูงเท่าระดับแม่น้ำแล้วจะหยุดรับน้ำ
   (น้ำส่วนนั้นค้างไหลต่อไปในแม่น้ำ — รายงานเป็น “ค้างในแม่น้ำ”)
2. **สมการการไหล** — แบบ local inertial (Bates et al. 2010, LISFLOOD-FP) บนตาราง DEM: น้ำไหลตามความต่างระดับผิวน้ำ
   ต้านด้วยความขรุขระ Manning n ตามการใช้ที่ดิน (นาข้าว 0.05, สวน/ชุมชน 0.10, ทุ่งหญ้า 0.04 ฯลฯ)
   ก้าวเวลาปรับตาม CFL อนุรักษ์มวลน้ำ (ทดสอบแล้ว) ระบบรวมเซลล์ให้ไม่เกิน 12,000 เซลล์อัตโนมัติ (~37–110 ม.)
   แล้วย่อระดับผิวน้ำกลับลง DEM ละเอียดเพื่อแสดงความลึก
3. **ผลตามเวลา** — ความลึกสูงสุด, ความเร็วและทิศทางสูงสุด, เวลาที่น้ำมาถึง (ลึก > 5 ซม.), ระยะเวลาท่วมขัง, ภาพรายชั่วโมง
4. **ระดับอันตรายต่อคน** (UK Defra/Environment Agency FD2320): HR = d × (v + 0.5) + DF
   (DF = 0 ถ้าลึก < 0.25 ม., 0.5 พื้นที่เกษตร, 1 ชุมชน/สวน)

   | HR | ระดับ | ความหมาย |
   |---|---|---|
   | < 0.75 | ต่ำ | เดินลุยน้ำได้ด้วยความระมัดระวัง |
   | 0.75–1.25 | ปานกลาง | อันตรายต่อเด็ก ผู้สูงอายุ ผู้ป่วย |
   | 1.25–2.0 | สูง | อันตรายต่อคนส่วนใหญ่ ควรอพยพ รถเล็กอาจลอย |
   | > 2.0 | รุนแรงมาก | อันตรายต่อทุกคน กระแสน้ำพัดคน/รถ |
5. **ความเสียหาย** — ความลึก → สัดส่วนความเสียหาย ตามรูปแบบฟังก์ชัน JRC (Huizinga et al. 2017 ภูมิภาคเอเชีย ค่าโดยประมาณ)
   แยก บ้านเรือน / นาข้าว-พืชไร่ / สวน-ไม้ยืนต้น × มูลค่าทรัพย์สิน (ค่าเริ่มต้น 2,500 บาท/ตร.ม. เขตชุมชน,
   5,500 บาท/ไร่ นาข้าว, 8,000 บาท/ไร่ สวน — ปรับได้ในหน้าตั้งค่า) และเพิ่มผลของแรงกระแสน้ำต่ออาคาร
   (Clausen & Clark 1990: d·v ≥ 3 ม.²/วินาที เสียหายหนัก ≥ 60%, d·v ≥ 7 พังทั้งหลัง)
