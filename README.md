# แผนที่คาดการณ์น้ำล้นตลิ่ง แม่น้ำแม่กลอง จ.ราชบุรี

ระบบแผนที่ดาวเทียมสำหรับประเมินว่า **เมื่อระดับน้ำแม่กลองเกินตลิ่ง น้ำจะแพร่กระจายไปถึงพื้นที่ใดบ้าง ลึกเท่าไร และเสียหายประมาณเท่าไร**
โดยใช้ **สถานี K.55A สะพานรถยนต์ค่ายหลวง อ.บ้านโป่ง** เป็นเกณฑ์หลัก ร่วมกับสถานีวัดระดับน้ำอื่นในจังหวัดราชบุรีจาก
คลังข้อมูลน้ำแห่งชาติ [thaiwater.net](https://www.thaiwater.net/)

## วิธีใช้งาน

```bash
node server.js          # ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม
# เปิด http://localhost:8080
```

`server.js` ให้บริการไฟล์หน้าเว็บ และเป็นตัวกลาง (`/api/thaiwater/waterlevel`) ดึงข้อมูลจาก
`api-v3.thaiwater.net` (แคช 5 นาที) เพื่อเลี่ยงปัญหา CORS ของเบราว์เซอร์
จะเปิดไฟล์ `index.html` ตรงๆ หรือวางบน GitHub Pages ก็ได้ ระบบจะลองเรียก API ของ ThaiWater โดยตรง
และถ้าไม่สำเร็จ สามารถคัดลอก JSON จาก thaiwater.net มาวางในช่อง “วาง JSON” ได้

### หน้าจอ

1. **ระดับน้ำที่สถานี K.55A** — เลือกป้อนเป็นปริมาณน้ำ (ลบ.ม./วินาที) หรือระดับน้ำ (ม.รทก.)
   ปุ่มลัดตาม Rating Curve (2,900–3,400 ลบ.ม./วินาที) พร้อมรูปตัดลำน้ำ และสถานะเทียบตลิ่งซ้าย 11.73 / ขวา 11.81 ม.รทก.
2. **ข้อมูลล่าสุดจาก ThaiWater** — รายการสถานีในราชบุรี (และใกล้แม่กลองในเขตคำนวณ) เรียงตามระดับที่เกินตลิ่ง
   🔴 น้ำล้นตลิ่ง · 🟠 ใกล้ล้น (< 0.5 ม.) · 🟢 ปกติ ถ้าพบสถานี K.55A ระบบจะตั้งค่าระดับน้ำปัจจุบันให้อัตโนมัติ
3. **ผลคาดการณ์** — ระบบจำลองการไหลของน้ำ 2 มิติตามเวลา (ค่าเริ่มต้น 48 ชม. ใช้เวลาคำนวณ 5–30 วินาที เห็นน้ำแผ่ออกบนแผนที่ระหว่างคำนวณ)
   แล้วสรุป: พื้นที่ท่วม, **ระดับอันตรายต่อคน** 4 ระดับ, **ความเร็ว/ความแรงของน้ำ**, พื้นที่น้ำไหลแรง ≥ 1 ม./วินาที,
   เขตบ้านเรือนที่เสี่ยงเสียหายหนัก, **ความเสียหายทางเศรษฐกิจแยกตามการใช้ที่ดิน** (บ้านเรือน / นาข้าว-พืชไร่ / สวน)
   และเงินช่วยเหลือเกษตรกรตามเกณฑ์ รายชื่อชุมชน (OpenStreetMap) เรียงตามระดับอันตราย พร้อมเวลาที่น้ำจะมาถึง
4. **แผนที่** — ภาพดาวเทียม Esri/Google เลือกชั้นแสดงผลได้ 5 แบบ:
   **ความลึก** · **ความแรงน้ำ** (สี + ลูกศรทิศทางการไหล) · **อันตราย** · **ความเสียหาย** (บาท/ตร.ม.) · **เวลาน้ำถึง**
   แถบเวลา/ปุ่ม ▶ เล่นย้อนดูน้ำแผ่ออกทีละชั่วโมง คลิกจุดใดก็ได้เพื่อดูความลึก ความเร็ว ทิศทางน้ำ เวลาที่น้ำมาถึง
   ระยะเวลาท่วมขัง ระดับอันตราย และความเสียหายต่อไร่ ณ จุดนั้น

## หลักการคำนวณ

### ขั้นที่ 1: จุดน้ำล้นและขอบเขตเสี่ยง (`js/flood.js`)

1. **ระดับน้ำตามลำน้ำ** — ระดับที่ K.55A (จาก Q หรือ H) เป็นจุดยึด ระดับที่จุดอื่นลดลงตามความลาดชันผิวน้ำ
   (ค่าเริ่มต้น 0.15 ม./กม. ได้จากแนวโน้มความสูงตลิ่งใน DEM ช่วงท่ามะกา–ราชบุรี)
   ถ้ามีข้อมูลสถานีอื่นในราชบุรี จะใช้ระดับตลิ่งของสถานีนั้นเป็นจุดควบคุมเพิ่ม และประมาณค่าระหว่างสถานีตามระยะทางลำน้ำ
2. **ระดับตลิ่งตามลำน้ำ** — ตลิ่งซ้าย/ขวาของ K.55A + ความลาดชัน + ส่วนที่ตลิ่งสูงกว่าแนวโน้มจาก DEM
   (เช่น ย่านเมือง ที่ดอน) คูณน้ำหนัก 0.5 — DEM ดาวเทียมสูงกว่าพื้นจริงหลายเมตรในเขตเมือง/ต้นไม้
   จึงใช้เพียงส่วนเบี่ยงเบนเฉพาะที่ ไม่ใช้ค่าสัมบูรณ์
3. **จุดน้ำล้น** — ช่วงลำน้ำที่ระดับน้ำ > ตลิ่งฝั่งนั้น (แยกฝั่งซ้าย/ขวา มองตามทิศน้ำไหล)
4. **การแพร่กระจาย** — น้ำไหลจากจุดล้นไปยังพิกเซลที่ติดกัน (8 ทิศ) ที่พื้นดินต่ำกว่าระดับน้ำ ต้องเชื่อมต่อกันเท่านั้น
   (แอ่งต่ำที่มีที่ดอนกั้นไม่นับ) และไม่เกินระยะแพร่กระจายสูงสุด (12 กม.)
   ผลนี้คือ “ขอบเขตเสี่ยงสูงสุด” (สีเหลือง) และเป็นโดเมนของการจำลองการไหลในขั้นที่ 2

### ขั้นที่ 2: การไหลของน้ำ ความแรง และความเสียหาย (`js/hydro.js`)

1. **ปริมาณน้ำที่ล้น** = Q ที่ K.55A − Q ตลิ่งเต็ม (≈ 2,938 ลบ.ม./วินาที) ไหลออกต่อเนื่องตามระยะเวลาที่ตั้ง
   แบ่งให้แต่ละจุดล้นตามสมการฝาย (ความสูงที่น้ำเกินตลิ่ง)^1.5 จุดใดที่น้ำบนตลิ่งสูงเท่าระดับแม่น้ำแล้วจะหยุดรับน้ำ
   (น้ำส่วนนั้นค้างไหลต่อไปในแม่น้ำ — รายงานเป็น “ค้างในแม่น้ำ”)
2. **สมการการไหล** — แบบ local inertial (Bates et al. 2010, LISFLOOD-FP) บนตาราง DEM: น้ำไหลตามความต่างระดับผิวน้ำ
   ต้านด้วยความขรุขระ Manning n ตามการใช้ที่ดิน (นาข้าว 0.05, สวน/ชุมชน 0.10, ทุ่งหญ้า 0.04 ฯลฯ)
   ก้าวเวลาปรับตาม CFL อนุรักษ์มวลน้ำ (ทดสอบแล้ว) ระบบรวมเซลล์ให้ไม่เกิน 12,000 เซลล์อัตโนมัติ (~37–110 ม.)
   แล้วย่อระดับผิวน้ำกลับลง DEM ละเอียดเพื่อแสดงความลึก
3. **ผลตามเวลา** — ความลึกสูงสุด, ความเร็วและทิศทางสูงสุด, เวลาที่น้ำมาถึง (ลึก > 5 ซม.), ระยะเวลาท่วมขัง, ภาพรายชั่วโมง
4. **ระดับอันตรายต่อคน** (UK Defra/Environment Agency FD2320): HR = d × (v + 0.5) + DF
   (DF = 0 ถ้าลึก < 0.25 ม., 0.5 พื้นที่เกษตร, 1 ชุมชน/สวน)

   | HR | ระดับ | ความหมาย |
   |---|---|---|
   | < 0.75 | ต่ำ | เดินลุยน้ำได้ด้วยความระมัดระวัง |
   | 0.75–1.25 | ปานกลาง | อันตรายต่อเด็ก ผู้สูงอายุ ผู้ป่วย |
   | 1.25–2.0 | สูง | อันตรายต่อคนส่วนใหญ่ ควรอพยพ รถเล็กอาจลอย |
   | > 2.0 | รุนแรงมาก | อันตรายต่อทุกคน กระแสน้ำพัดคน/รถ |
5. **ความเสียหาย** — ความลึก → สัดส่วนความเสียหาย ตามรูปแบบฟังก์ชัน JRC (Huizinga et al. 2017 ภูมิภาคเอเชีย ค่าโดยประมาณ)
   แยก บ้านเรือน / นาข้าว-พืชไร่ / สวน-ไม้ยืนต้น × มูลค่าทรัพย์สิน (ค่าเริ่มต้น 2,500 บาท/ตร.ม. เขตชุมชน,
   5,500 บาท/ไร่ นาข้าว, 8,000 บาท/ไร่ สวน — ปรับได้ในหน้าตั้งค่า) และเพิ่มผลของแรงกระแสน้ำต่ออาคาร
   (Clausen & Clark 1990: d·v ≥ 3 ม.²/วินาที เสียหายหนัก ≥ 60%, d·v ≥ 7 พังทั้งหลัง)

## ข้อจำกัด (โปรดอ่าน)

- การจำลองการไหลเป็นแบบ 2 มิติอย่างง่าย **ยังไม่ใช่แบบจำลองที่สอบเทียบกับเหตุการณ์จริง** ไม่รวมน้ำฝน น้ำจากลำน้ำสาขา
  การระบายของประตูระบายน้ำ ถนน/คันกั้นน้ำขนาดเล็กที่ DEM 30 ม. มองไม่เห็น และถือว่า Q คงที่ตลอดช่วงเวลา
- ความเร็วสูงสุดบางจุด (> 3 ม./วินาที) มักเกิดจากขอบชันของ DEM จึงควรดูค่า P99 เป็นหลัก
- มูลค่าความเสียหายขึ้นกับค่ามูลค่าทรัพย์สินที่ตั้งไว้ (โดยเฉพาะเขตบ้านเรือน) ควรปรับตามข้อมูลจริงของพื้นที่
- DEM ดาวเทียมมีความคลาดเคลื่อน ±2–5 ม. ในเขตเมืองและพื้นที่ต้นไม้ ปรับได้ที่ “ปรับแก้ DEM”
- ระดับตลิ่งของจุดอื่นนอกจาก K.55A เป็นค่าประมาณ ถ้ามีระดับตลิ่งสำรวจจริงของสถานีอื่น ควรเพิ่มเข้าไปเป็นจุดควบคุม
- พิกัดสถานี K.55A ในไฟล์ตั้งค่าเป็นค่าประมาณ (ลากหมุดเพื่อแก้ไขได้) และจะใช้พิกัดจาก ThaiWater ถ้ามี
- ผลลัพธ์ใช้ประกอบการเฝ้าระวังและวางแผนเท่านั้น **ให้ยึดประกาศของกรมชลประทาน ปภ. และจังหวัดราชบุรีเป็นหลัก**

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก
css/app.css             รูปแบบการแสดงผล (รองรับมือถือและโหมดมืด)
js/config.js            ค่าตั้งต้น: Rating Curve, ตลิ่ง, ขอบเขตพื้นที่, พารามิเตอร์แบบจำลอง
js/rating.js            แปลง Q ↔ H และสถานะเทียบตลิ่ง
js/flood.js             จุดน้ำล้นและขอบเขตเสี่ยง (ใช้ได้ทั้งเบราว์เซอร์และ Node)
js/hydro.js             จำลองการไหล 2 มิติ ระดับอันตราย ความเสียหาย
js/dem.js               โหลด DEM จาก AWS Terrain Tiles
js/thaiwater.js         ดึง/แปลงข้อมูลระดับน้ำจาก ThaiWater
js/app.js               แผนที่ Leaflet และส่วนติดต่อผู้ใช้
data/maeklong-river.js  เส้นกึ่งกลางแม่น้ำแม่กลองสำรอง
data/landcover.js       การใช้ที่ดิน ESA WorldCover (ฝังเป็น PNG)
server.js               เซิร์ฟเวอร์ + ตัวกลางดึงข้อมูล ThaiWater
tools/scenarios.js      คำนวณตารางสถานการณ์จากบรรทัดคำสั่ง
test/*.test.js          ชุดทดสอบ (npm test)
vendor/leaflet/         Leaflet 1.9.4 (BSD-2-Clause)
```
